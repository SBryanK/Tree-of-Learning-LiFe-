# Reusable Tree prompts

These are newly consolidated prompts based on the visible Tree requirements, not verbatim exports of historical messages.

## Continue a project

Read AGENTS.md, docs/PROJECT-MAP.md and docs/SYNC-STATUS.md. Then read the selected project's STATE.md and relevant source files. Explain the current scope and next step briefly, then complete the work. Preserve progress IDs, document coverage honestly, run relevant checks, update the checkpoint, commit and push reviewed original outputs to the canonical Tree repository. Report the commit and remaining gaps.

## Build a learning artifact

Read the supplied material, including meaningful diagrams and tables. Use setup-project-context and design-study-studio when available; do not claim to use unavailable skills. Build a usable bilingual interactive learning artifact with technical terms in English and explanations in Bahasa Indonesia. Teach concept → mechanism → worked example → practice → milestone. Include roadmap, glossary, concept map, flashcards, scenario questions with explanations, progress persistence and export/import where supported. Distinguish source indexed/read/authored from learner mastery. Keep sources and coverage inspectable; document unfinished material. Save editable source, build instructions and STATE.md, test the important interactions, then follow the Tree GitHub rules.

## Import historical work

Import the provided Tree chat export or artifact files into this repository. Preserve originals only when suitable for this public destination; otherwise retain original derived learning notes and source links. Do not infer missing messages or expose credentials/private learner content. Organize by topic, keep dates and provenance, update the project map and sync gaps, validate links and files, then commit and push. State precisely what was imported and what remains unavailable.
