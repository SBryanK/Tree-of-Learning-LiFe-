# Arah study hub

Primary task: mencoba diagnostic, lalu belajar satu keputusan arsitektur dengan bukti. Permukaan seperti buku kerja arsitek: daftar sesi di kiri, bacaan di tengah, aksi recall dekat materi. Tampilan awal langsung menawarkan diagnostic.

Palet: latar putih hangat, teks biru gelap, teal untuk link dan fokus, amber berlabel untuk status belum dinilai. System sans 17px untuk bacaan, Georgia untuk judul, measure sekitar 70ch; kontrol 12px, kelompok 18px. Konten panjang tetap terbuka; kelompok visual hanya untuk soal dan navigasi.

Tidak ada animasi yang menghambat membaca. Gunakan HTML semantik, focus ring, ukuran kontrol nyaman, table scroller, layout satu kolom di layar sempit. Status membaca/self-rating terpisah dari hasil tutor. Draft browser tersimpan lokal, tidak tersinkron ke chat. Ekspor JSON berisi catatan pribadi; tidak ada auto-send.

Ruang lingkup versi awal: satu modul, bukan seluruh silabus. Diagnostic tidak menyertakan kunci jawaban. Materi Markdown adalah sumber yang dapat diedit dan dipindahkan.
